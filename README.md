# My Minimal PWA Portfolio Website
![a cropped screenshot of my minimal pwa portfolio website developed using react](./public/portfolio.png)

This is my portfolio project that I first designed and developed in 2024.

## Description
I used <code style="color : lightskyblue">React.js</code> as a powerfull tool to achieve my goals:
- A single page application with a great performance
- Good code readability
- Having fun!

I designed and made it with Responsive Design Principles in mind.

## Live test
I deployed my website on **GitHub Pages** using **GitHub WorkFlows**.

So, feel free to check [My Minimal PWA Portfolio](https://moeini-dev.github.io/portfolio/) online.

It also has the ability to get added to your phone's home screen as an app.
## Stack
I practically used the minimum required technologies to make my protfolio simple, quick, and easy to maintain.\
This is the the stack I utilized:
- HTML
- CSS
- JavaScript (In JSX form)
- React.js
- Vite
